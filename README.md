# Nadin Fink — Portfolio

Personal portfolio website of Nadin Fink, UX/UI Designer and Web Designer.

## Live Website

https://nadia-portfolio-dun.vercel.app/

## About

A responsive portfolio showcasing selected UX/UI, web design, Webflow and interactive projects.

The portfolio combines visual design, motion, responsive layouts and frontend implementation in a dark futuristic interface.

## Focus Areas

- UX/UI Design
- Web Design
- Webflow
- Motion & Prototyping
- Interactive Interfaces
- Frontend
- UX Research
- AI Visuals

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Vercel

## Features

- Responsive design for desktop, tablet and mobile
- Separate hero background videos for desktop and mobile
- Animated typewriter and motion effects
- Project case studies
- Open Graph sharing preview
- Contact form powered by Web3Forms
- Responsive navigation and layouts

## Selected Projects

The portfolio includes projects in UX/UI design, Webflow, frontend and visual experimentation.

## Deployment

The project is deployed with Vercel and connected to the `main` branch for automatic production updates.
